Qwen Multiangle in ComfyUI
This is an open-source node that takes a reference image and produces new views from different camera angles while keeping the subject, details, and background consistent. It uses the LoRA qwen-image-edit-2511-multiple-angles-lora.safetensors. The tutorial’s tip is to use the same seed for every angle and change only the camera angle between runs. Tutorial: https://www.earngenix.com/tutorials/qwen-multiangle-comfyui-workflow
