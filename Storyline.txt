Max friendship --> Unlock --> Game (Clicker, ...) --> Zo verder
Friendship points --> Goeie keuzes nemen
Verlies points --> Slechte keuzes
Friendship points nodig om maximum te zijn verschilt per character
Alle FP worden in een combinatie gestoken als in-game currency voor skins, etc.

MENU: Characters GUI --> toon alle girls met een slot als je ze nog niet heb unlocked, als je ze wel hebt unlocked toon de FP per character en toon een % met hoeveel je al van de character dialogue hebt unlocked, je kan dan ook per character klikken zodat je iedere dialogue kan zien met de resultaten erbij van je vorige run ( Je kan ze ook replayen, om betere resultaten te krijgen. Als je bv Negatief uitkomt ).
 
Skin GUI --> Waar je de characters ziet, die een skin kunnen krijgen met unlocked/locked ( bij locked kan je dan de skin kopen voor bepaald FP ) , Je kan ze dan ook equippen wanneer ze unlocked zijn.

Minigame GUI --> Toon alle minigames die je hebt unlocked, een slot achter de gene die je nog niet hebt unlocked.

Skins en minigames worden in een SHOP GUI gestopt onder Play

dus Main menu GUI wordt als volgt;
PLAY --> Start New Game, Continue, Load Game
SHOP --> SKINS GUI, MINIGAME GUI
SETTINGS --> Alle instellingen worden nog later besproken
QUIT --> Leaved de game

REWARD SYSTEM ;
het 100% van een character ( DUS ALLE DIALOGUES POSITIEF ) geeft je al een minigame die je unlocked maar nog moet kopen met FP, Dan wanneer je een bepaald aantal characters 100% krijg je nog extra FP of Extra Skins/Minigames

Characters naam is nog niet gerevealed totdat ze het zelf zegt hoe ze noemt!!!

Ieder character heeft ander background ( ANDER VERHAAL )
